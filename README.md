# مشروع مكتبتي (Maktabati SaaS) - وثيقة المعمارية وهندسة النظام

نظام سحابي متعدد المستأجرين (Multi-Tenant SaaS) مخصص للمكتبات ومراكز الطباعة الرقمية والقرطاسية، مصمم بواجهة عربية كاملة (RTL) واستجابة فائقة على أجهزة الهاتف والكمبيوتر.

---

## 3. تفاصيل قاعدة البيانات ومستودعات التخزين (Storage & Database)

### الجداول الأساسية المنجزة في `schema.sql`:
1. **`tenants`:** بيانات المكتبة المشتركة، الباقة، ومعاملات التفعيل `feature_flags`.
2. **`branches`:** الفروع، العملة، سعر الصرف، إعدادات شام كاش، ورمز مصادقة وكيل الطباعة.
3. **`profiles`:** صلاحيات الموظفين والمديرين والملاك المرتبطة بـ `auth.users`.
4. **`print_pricing` & `print_services`:** مصفوفة أسعار الطباعة والخدمات الإضافية (تجليد، تغليف، تكبيس).
5. **`notes_catalog`:** مكتبة النوط والملخصات وتصنيفها الأكاديمي.
6. **`print_orders`:** طابور الطلبات المتصل لحظياً عبر `Realtime` مع رقم يومي تلقائي لكل فرع (`#101` فما فوق).
7. **`print_audit_logs`:** سجل عداد الأوراق والصفحات (ملون / أسود) لمراقبة الاستهلاك والمداخيل بدقة.
8. **جداول جاهزة مسبقاً للمرحلتين 2 و 3:** (`pos_categories`, `pos_items`, `branch_inventory`, `inventory_transfers`).

### مستودعات التخزين (Supabase Storage Buckets):
- **`customer-files`:** لملفات الزبائن المؤقتة (PDF/صور).
- **`payment-receipts`:** لصور إيصالات تحويل شام كاش.
- **`notes-catalog-files`:** للنوط والملخصات الرسمية للمكتبة.
- **`branding`:** لشعار المكتبة وصورة QR حساب شام كاش.

### آلية الحذف التلقائي والحفاظ على الخصوصية:
- دالة `purge_expired_customer_files()` تحذف روابط الملفات وتفرغها بعد إتمام الطلب أو بمرور 24 ساعة لضمان توفير المساحة والسرية التامة لملفات الزبائن.
